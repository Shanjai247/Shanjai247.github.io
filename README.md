# Shanjai Pushparaj Portfolio Website

A clean GitHub Pages portfolio website for embedded systems, IoT, PCB design, robotics, and hardware R&D roles.

## How to publish on GitHub Pages

1. Create a GitHub account or log in.
2. Create a new public repository named:
   `shanjaipushparaj.github.io`
3. Upload all files from this folder into the repository.
4. Go to **Settings > Pages**.
5. Under **Build and deployment**, choose:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: /root
6. Save.
7. Your website should be live at:
   `https://shanjaipushparaj.github.io`

## What to update before publishing

- Replace LinkedIn URL in `index.html`.
- Replace GitHub URL in `index.html`.
- Add project images into `assets/projects/`.
- Replace placeholder project image boxes with actual image tags.
- Confirm whether the degree status should say `Graduate`, `Expected Oct 2026`, or `2022 – 2026`.
- Add GPA if you want it shown.
