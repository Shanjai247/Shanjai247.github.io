EEG-Based Wearable System for Sleep Quality Assessment

A low-cost wearable EEG headband system developed as a final year research project to assess sleep quality using frontal EEG signals, embedded TinyML inference, BLE communication, and a Flutter mobile application.

Problem

University students often use screens before sleep, but most consumer tools only count screen time or estimate sleep indirectly. This project explored a wearable EEG-based system that directly measures brain activity during sleep and converts sleep-stage information into a simple sleep quality score.

Solution

The system records frontal EEG using dry electrodes and an analog front-end, digitizes the signal, extracts features, stores overnight data, runs TinyML sleep-stage inference on an STM32 microcontroller, calculates a sleep score, and sends the result to a Flutter mobile application using Bluetooth Low Energy.

My Contribution

  • Designed the custom 4-layer STM32H743VIT6 main PCB including schematic, routing, grounding strategy, and power distribution in EasyEDA.
  • Integrated STM32, ESP32, ADS1220 ADC, BioAmp EXG Pill, microSD storage, BLE module, and battery-powered architecture.
  • Contributed to the embedded pipeline involving EEG acquisition, DSP filtering, feature extraction, UART/SPI communication, TinyML inference, sleep scoring, and BLE result transfer.
  • Validated the TinyML deployment pipeline on STM32 using ST Edge AI Studio, with the final INT8 model using approximately 22 KB flash and 1.67 KB RAM.

Outcome

  • Final TinyML model achieved 83.79% test accuracy on the Sleep-EDF dataset.
  • Custom 4-layer PCB gave practical experience in high-density embedded hardware design.
  • End-to-end system demonstrated EEG data flow from wearable hardware to mobile app display.
