Problem

The goal was to create a simple wireless control system for a mobile robot without using a separate mobile application.

Solution

The ESP32 hosts a local Wi-Fi web page with movement controls. User commands from the web interface are converted into motor driver signals through the L298N to control forward, reverse, left, and right movement.

My Contribution

  • Built ESP32-based Wi-Fi control logic and web interface.
  • Integrated L298N motor driver for DC motor movement.
  • Tested wireless movement control through a browser-based interface.

Outcome

  • Completed a functional Wi-Fi-controlled robotic car prototype and strengthened embedded networking and motor control basics.
