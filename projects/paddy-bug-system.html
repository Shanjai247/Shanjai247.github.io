Paddy Bug Detection & Repellent System

An acoustic pest detection and repellent system designed to detect paddy bug activity using microphone-based audio sensing, filtering, FFT-based analysis, and wireless field communication.

Problem

Paddy bug infestations can damage agricultural crops, and manual monitoring is difficult across large fields. The project explored an embedded acoustic method to detect and respond to pest activity.

Solution

The system used microphone-based audio acquisition and signal processing to identify relevant acoustic patterns. LoRa communication was explored for pole-to-pole field communication, enabling distributed detection and response across a paddy field.

My Contribution

  • Implemented real-time audio analysis concepts using IIR filtering and FFT-based signal processing.
  • Worked with INMP441 microphone interfacing on ESP32.
  • Explored LoRa-based communication for distributed pole-mounted field units.
  • Contributed to the design of a smart pole-mounted detection and repellent system concept.

Outcome

  • Built a prototype-level embedded sensing project combining audio processing, wireless communication, and agricultural application.
  • Strengthened skills in signal processing, sensor interfacing, and IoT-based field systems.
