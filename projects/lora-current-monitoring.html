LoRa-Based Current Monitoring System

A wireless load-current monitoring prototype developed during industrial training at Volt Charge Sri Lanka using ESP32, RA-01 LoRa modules, current transformer clamps, signal conditioning, and CRC16 packet validation.

Problem

The system needed a practical way to measure load current and transmit current readings wirelessly over a longer distance with reliable packet validation and low hardware complexity.

Solution

A sender unit measured current using CT clamps and an ESP32 ADC after signal conditioning. The readings were formatted into compact LoRa packets with CRC16 validation and transmitted to a receiver unit for load monitoring support.

My Contribution

  • Designed CT signal conditioning including burden resistor selection, 1.65 V ADC biasing, and filtering.
  • Developed ESP32 firmware for current measurement, LoRa transmission, and packet validation.
  • Implemented CRC16 error detection to reject corrupted packets.
  • Tested multiple 433 MHz antenna configurations and selected a practical quarter-wave antenna.
  • Prepared sender and receiver schematics in KiCad and built an enclosed proof-of-concept prototype.

Outcome

  • Wireless current data transmission was tested successfully over approximately 100 m.
  • RMS current readings were calibrated against an ADL400-D reference energy meter.
  • The project improved practical skills in embedded firmware, LoRa communication, ADC measurement, antenna tuning, soldering, and system testing.
