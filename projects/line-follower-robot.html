Problem

Basic line followers can become unstable during turns and path changes when using simple threshold-based control. This project explored fuzzy logic to improve motor response.

Solution

The robot reads line position using a 5-bit IR sensor array and adjusts motor speeds through a TB6612FNG driver. Fuzzy logic is used to determine smoother left/right correction based on sensor error.

My Contribution

  • Integrated ESP32 with the 5-bit IR sensor array and TB6612FNG motor driver.
  • Implemented fuzzy-logic-based motor control for autonomous line following.
  • Tested robot movement across turns and path changes.

Outcome

  • Built a working autonomous robot prototype and gained practical experience in sensor-based control and motor driver integration.
