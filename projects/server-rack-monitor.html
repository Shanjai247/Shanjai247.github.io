Smart Server Rack Monitoring System

A local rack-level monitoring system for observing multi-point temperature, humidity, voltage, rack health index, and threshold-based alarms using ESP32 data acquisition and LabVIEW visualization.

Problem

Server racks can experience thermal stratification, humidity variation, and unstable electrical conditions. Monitoring only one point is not enough to detect abnormal rack behavior reliably.

Solution

The ESP32 samples distributed sensors and transmits structured serial data to LabVIEW. LabVIEW parses the data, calculates derived metrics such as temperature differentials and rate of rise, evaluates threshold conditions, and displays rack status through numeric indicators and alarms.

My Contribution

  • Implemented ESP32-based sensor acquisition and structured ASCII serial data transmission.
  • Supported multi-point temperature, humidity, and voltage monitoring logic.
  • Built LabVIEW visualization with numeric indicators, meters, Boolean alarms, and rack health status.
  • Designed threshold-based monitoring for over-temperature, excessive temperature difference, voltage limits, and rack health index warnings.

Outcome

  • Created a working lab-demonstrable monitoring system for rack environmental and electrical status.
  • Improved experience in serial communication, dashboard visualization, threshold logic, and embedded data acquisition.
